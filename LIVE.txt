CyberSym SecureTrade — going live (real Coinbase orders)
========================================================

Paper trading and live market data are already on.
This add-on sends REAL Coinbase market orders with YOUR money.

What goes live
--------------
• Coinbase-only triangles (buy/sell all on Coinbase).
• Each tap is $1–$25 (default $5). Buttons: $1 $2 $3 $4 $5 …
• Session budget: $25 total live size this run (five $5 taps, or
  twenty-five $1 taps, etc.). Coins priced under $1 still buy a fraction.
• Every live order is a tap. Auto-invest stays off while live.

What stays paper
----------------
• Buy Coinbase / sell Kraken (or Gemini / Bitstamp).
  You cannot instantly move coins between exchanges, so those
  fills stay simulated even in live mode.

You can lose money. Fees and slippage eat most retail gaps.
This is not a profit guarantee.

Setup (once)
------------
1. Create a Coinbase Advanced Trade / Coinbase App API key (this is
   YOUR Coinbase account, not a CyberSym login):
     https://portal.cdp.coinbase.com/projects/api-keys
   Sign in with the same Coinbase account that holds your USD.
   Click Create API key.
   Nickname: anything, e.g. SecureTrade.
   Permissions: View + Trade. Do NOT enable Transfer / Send / Withdraw.
   Signature algorithm: ECDSA (not Ed25519).
   Coinbase no longer auto-downloads the file. In the popup, click
   Download API key. The secret is shown only once.

2. Rename that download to coinbase.json and put it here
   (same folder as start.bat):
     keys\coinbase.json

3. Leave some USD (and a little BTC/ETH if you want sell legs) in Coinbase.
   You need at least the live cap in USD/USDC/USDT (default $25).

4. Stop the demo window first (close the black window).

5. Check first (does not send orders):
   Windows:  double-click CHECK-LIVE.bat
   Mac:      double-click Check-Live.command
   Linux:    ./check-live.sh

6. When the check says Ready:
   Windows:  double-click GO-LIVE.bat
   Mac:      double-click Go-Live.command
   Linux:    ./go-live.sh

GO-LIVE runs the same check again and will refuse to start if it fails.

You will be asked to confirm. The dashboard shows a red LIVE banner,
your balances, and the $25 cap. The black window prints a lock PIN.
This computer's browser unlocks by itself. iPad: enter that PIN.
Use Kill switch or close the window to stop new orders. A failed live
order also trips the kill switch.

If CHECK-LIVE says Coinbase did not accept the key:
the key must be a Coinbase App / Advanced Trade Secret API key
(View + Trade, ECDSA) from
  https://portal.cdp.coinbase.com/projects/api-keys
A cloud-only CDP key will not work. Download a new JSON and replace
keys\coinbase.json, then run CHECK-LIVE.bat again.

If Coinbase auth fails, the app will not start live. Fix the JSON
and try again. Never paste keys into the dashboard or email.

If CHECK-LIVE says the key cannot sign (cryptography / openssl):
close other SecureTrade windows, double-click INSTALL.bat, then
CHECK-LIVE.bat again. That repairs the Coinbase signing library
for this Python. Do not copy .venv from another folder.
