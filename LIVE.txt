CyberSym SecureTrade — going live (real orders)
================================================

Paper trading and live market data are already on.
This add-on sends REAL market orders with YOUR money on the
exchange you pick: Coinbase or Kraken. You do not need both.

Paper and live are on the SAME dashboard. Start with paper
(start-live.bat). Pick Live on: Coinbase or Kraken. When the
Ready check is green, switch Paper → Live.
You can switch back to Paper any time without closing the app.
GO-LIVE.bat still starts already live if you want that.

What goes live
--------------
• Same-exchange USD round-trips on the venue you picked:
  USD vs USDC dislocations (buy cheap, sell rich, convert leftover
  USDC back to USD) and same-exchange triangles — including Kraken
  FX (EUR-USD, GBP-USD, EUR-GBP) from Kraken’s own ticker.
• Yahoo FX is delayed and watch-only. It is not a live feed.
  Coinbase does not list EUR-USD; it lists USDC-EUR / USDC-GBP.
• Buys are market. Sells and flatten post a maker limit (Kraken ~16 bps,
  Coinbase ~40 bps) then market whatever is unfilled after ~8 seconds.
  That is the cost cut. It is not a profit guarantee.
• Each tap starts in USD and aims to finish in USD.
• Each tap is $1–$25 (default $5). Session budget: $25 this run.
• P&L is from actual fill prices, not the estimated edge.

Auto window
-----------
• Paper Auto can run any time, or only between the times you set
  (example: 10:00 PM to 6:00 AM — overnight wraps midnight).
• Times use THIS computer’s clock.
• While live, Auto stays off unless you turn on “Only between”
  and set a start and stop. Then Auto can fire inside that window
  on the live venue only. Kill switch still pauses new orders.

What stays off live (would mean holding)
----------------------------------------
• Buy Coinbase / sell Kraken (or Gemini / Bitstamp).
  You cannot instantly move coins between exchanges. Paper can fake
  that round-trip; live cannot without parking coins on both books.
• Gemini and Bitstamp stay paper (live is Coinbase or Kraken).

You can lose money. Fees and slippage eat most retail gaps.
This is not a profit guarantee.

Setup (once) — Coinbase
-----------------------
1. Create a Coinbase Advanced Trade / Coinbase App API key:
     https://portal.cdp.coinbase.com/projects/api-keys
   Permissions: View + Trade. Do NOT enable Transfer / Send / Withdraw.
   Signature algorithm: ECDSA (not Ed25519).
   Download API key and save as keys\coinbase.json

Setup (once) — Kraken
---------------------
Kraken does NOT download a file. You copy the two values it shows
(API Key and Private Key) into a small JSON file yourself.

1. Create a Kraken API key:
     https://www.kraken.com/u/security/api
   Permissions: Query Funds + Create & Modify Orders.
   Do NOT enable Withdraw.
   Copy both values before you close the page. The private key is
   shown only once.

2. In the same folder as start.bat, open the keys folder.
   Copy keys\kraken.json.example and rename the copy to kraken.json
   (Notepad: File → Save As → File name: kraken.json
    Save as type: All Files. Not kraken.json.txt.)

   The file must look like this — one line of key, one line of secret,
   both in quotes, no extra commas:

     {
       "key": "PASTE_THE_API_KEY_HERE",
       "secret": "PASTE_THE_PRIVATE_KEY_HERE"
     }

   Kraken’s “API Key” goes in "key".
   Kraken’s “Private Key” (long, often with + / =) goes in "secret".
   Keep it all on those two fields. Do not email this file.

3. Leave USD (dollars), not only USDC, on that exchange — at least
   the $25 session cap. CHECK-LIVE used to count USDC as cash and
   then block the first tap. You do not need to hold BTC/ETH for
   sell legs. Each tap spends USD, then sells back toward USD. It
   will not sell coins you already had. A $10 tap does not create
   an edge, and Kraken BTC often needs more than $10 to clear the
   pair minimum.

4. Stop the demo window first (close the black window).

5. Check first (does not send orders):
   Windows:  double-click CHECK-LIVE.bat
   Mac:      double-click Check-Live.command
   Linux:    ./check-live.sh

6. When the check says Ready:
   Windows:  start-live.bat, then pick Live on: Kraken, then switch to Live
             (or double-click GO-LIVE.bat to start already live)
   Mac:      start.command for paper, or Go-Live.command
   Linux:    ./start.sh for paper, or ./go-live.sh

You confirm Live on the dashboard (or GO-LIVE.bat). The dashboard shows a red
LIVE banner, your balances, and the $25 cap. Switch back to Paper any time.
This computer's browser unlocks by itself. iPad: enter that PIN.
Use Kill switch or close the window to stop new orders. Leftover coins
from a tap that cannot be sold back to USD pause new orders (Resume).
You stay on Live until you click Paper.

If CHECK-LIVE says Coinbase did not accept the key:
the key must be a Coinbase App / Advanced Trade Secret API key
(View + Trade, ECDSA) from
  https://portal.cdp.coinbase.com/projects/api-keys
A cloud-only CDP key will not work. Download a new JSON and replace
keys\coinbase.json, then run CHECK-LIVE.bat again.

If Coinbase auth fails, the app will not start live on Coinbase. Fix the JSON
and try again — or pick Kraken if that is the account you have.
Never paste keys into the dashboard or email.

If CHECK-LIVE says the key cannot sign (cryptography / openssl):
close other SecureTrade windows, double-click INSTALL.bat, then
CHECK-LIVE.bat again. That repairs the Coinbase signing library
for this Python. Do not copy .venv from another folder.
