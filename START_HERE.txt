CyberSym SecureTrade — download and install
==========================================

A CyberSym product.

Versions 1.4 and 1.5 are withdrawn (Windows encodings crash).
If several Pythons are installed, the app uses C:\Python314\python.exe first
(not "py -3"). To force another, put one line in python-path.txt next to
start.bat, for example: C:\Python314\python.exe
Unzip into a NEW folder. Do not copy .venv from 1.4 or 1.5.

1. Unzip this folder anywhere.
2. Install Python 3.11+ if needed: https://www.python.org/downloads/
   Windows: tick "Add python.exe to PATH".
3. Install the app:
   • Windows:  double-click INSTALL.bat
   • Mac:      double-click Install.command
   • Linux:    ./install.sh
4. Start it:
   • Windows:  double-click start.bat
   • Mac:      double-click start.command
   • Linux:    ./start.sh
5. Open http://127.0.0.1:8080
   The black window prints a lock PIN. This computer's browser unlocks
   by itself. Phone or iPad: type that PIN.

Company logo: copy your CyberSym crest PNG into
   branding\cybersym-logo.png
then refresh the page (Ctrl+F5). Windows: Use-This-Logo.bat opens that folder.

First launch can take a few minutes while packages install.
Leave the black window open while you use the dashboard. Close it to stop.
If you see "port already in use", close the other SecureTrade window — or just
start again; it will use 8081, 8082, and so on automatically.

This first run is DEMO / PAPER TRADING. No exchange keys. No real orders.

On the dashboard, use Look → Dark or Light. Use Sound → Off if you do
not want the chime. Sound dings for a new matching setup and again
when a trade completes. Toasts still appear if sound is off.

On the dashboard, set How much to invest, pick your coins, then tap
Invest on a trade — or turn on Invest automatically (paper only).
While live Coinbase orders are armed, Auto stays off so every real
order is a tap.

Profit / trades spreadsheet:

Profit / trades spreadsheet:
   While the scanner is running it writes:
      data\CyberSym-SecureTrade-profit-report.csv
   If the dashboard Export button does nothing, open that file in Excel
   (do not stop the 12-hour run). On Windows you can also double-click
   Open-Report.bat — it copies the file to your Desktop and opens it.

On the dashboard, click "Export report" to download the same spreadsheet.

Live market data (still paper trading):
   Windows:  start-live.bat
   Mac/Linux: ./start.sh --live

Real Coinbase orders (your money):
   Read LIVE.txt first.
   Create the key at https://portal.cdp.coinbase.com/projects/api-keys
   Download API key, save as keys\coinbase.json
   Windows:  double-click CHECK-LIVE.bat, then GO-LIVE.bat
   Mac:      double-click Check-Live.command, then Go-Live.command
   Linux:    ./check-live.sh && ./go-live.sh
   Default cap is $25 per trade. Cross-venue stays paper.
   Auto stays off while live.
