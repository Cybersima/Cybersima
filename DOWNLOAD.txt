Download CyberSym SecureTrade
=============================

This zip is the installer. You do not need GitHub.

Unzip into a NEW folder (not on top of 1.4 / 1.5). Then:

  Windows:  double-click INSTALL.bat, then start-live.bat
  Mac:      double-click Install.command, then start.command
  Linux:    ./install.sh && ./start.sh --live

You need Python 3.11+ from https://www.python.org/downloads/
Windows: tick "Add python.exe to PATH".
If several Pythons are installed, the app uses C:\Python314\python.exe
first, not "py -3". Optional: python-path.txt next to start.bat with one
line = full path to python.exe.

Dashboard: http://127.0.0.1:8080
start-live.bat = live prices, paper trades. Practice on Paper.
GO-LIVE.bat still starts already live if you prefer.

Profit report (Excel): data\CyberSym-SecureTrade-profit-report.csv
Windows: double-click Open-Report.bat if the Export button does not download.

Real Coinbase or Kraken orders: read LIVE.txt, then CHECK-LIVE.bat.
