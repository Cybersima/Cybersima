# Download CyberSym SecureTrade 2

Use **CyberSym-SecureTrade-2.zip** in this folder.

1. Download the zip.
2. Unzip it.
3. Windows: double-click `start.bat`  
   Mac: double-click `start.command`  
   Linux: run `./install.sh` then `./start.sh`
4. Open http://127.0.0.1:8000

You need Python 3.11 or newer. Paper trading is the default.
